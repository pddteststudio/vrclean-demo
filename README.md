# VR Clean — независимый демосайт

Готовый одностраничный сайт-визитка для демонстрации компании VR Clean (Казань).

**Важно:** это неофициальный концепт, не связанный с VR Clean. Настоящие заявки и персональные данные не отправляются и не сохраняются. Сайт намеренно закрыт от поисковой индексации.

## Содержимое

- `index.html` — готовая страница (HTML5 + встроенная SVG-система и доступная семантическая разметка).
- `assets/styles.css` — адаптивная вёрстка, анимации, эффекты при наведении, поддержка reduced motion.
- `assets/app.js` — мобильная навигация, вкладки, FAQ, конструктор запроса, копирование текста и проверки ввода.
- `assets/config.js` — информация о VR Clean, цены из открытых каталогов и блокировка настоящих заявок.
- `assets/svg/*.svg` — 11 оригинальных векторных иллюстраций, включая первый экран, 6 услуг и 4 этапа.
- `favicon.svg` — иконка сайта.
- `robots.txt`, `vercel.json` — запрет на индексацию и заголовки безопасности.

Никаких `node_modules`, npm, сборки, базы данных и внешних библиотек JavaScript не требуется. Шрифт Manrope загружается через Google Fonts с системным fallback.

## Локальный запуск

Вариант 1: просто откройте `index.html` в браузере (активны относительные пути).

Вариант 2: в каталоге проекта выполните:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`.

Вариант 3: откройте предоставленный рядом файл `VR_Clean_preview.html` — это автономный просмотр с включёнными SVG и стилями.

## Vercel

1. Создайте репозиторий GitHub `vrclean-website` и загрузите **содержимое** этого каталога в корень репозитория.
2. В Vercel выберите `Add New → Project`, импортируйте репозиторий.
3. Framework Preset: **Other** (статический сайт). Build Command: **не требуется**. Output Directory: **не задавайте вручную**, если Vercel корректно распознаёт корневой `index.html`.
4. Project Name: `vrclean-demo` (если свободно). Подтвердите Deploy.
5. Проверьте реальный URL, меню, изображения, калькулятор, наличие noindex и работу на телефоне.

Имя репозитория и Vercel: `vrclean-website`, `vrclean-demo`. Название коммита: `feat: launch independent VR Clean website demo`.

## Тестирование

Протестировано в локальном Chromium в эмулированных размерах **1440, 768, 390, 360 px**. Проверены отсутствие горизонтального переполнения, отсутствие ошибок JavaScript, вкладки, выбор услуг, сохранение выбранной услуги в конструкторе, доп. задачи, валидация площади, сброс, просмотр текста, копирование запроса и мобильное меню. Из-за ограничений среды скриншоты делались с локально встроенными ассетами, но логика и CSS соответствуют архиву. Реальную публикацию на Vercel необходимо проверить после загрузки.
